# PostCheck pilot

PostCheck reads an event flyer, fills in the fields of EngageXU's Create Event form, asks about anything the flyer leaves out, and lists each checked field ready to paste into EngageXU. It's a student project.

- **Website:** https://kjryan2004-arch.github.io/postcheck-pilot/
- **App:** https://kjryan2004-arch.github.io/postcheck-pilot/app/

The app reads flyers on your own device (Tesseract.js, downloaded the first time), so nothing is uploaded. It can't post to EngageXU directly; you paste the checked fields in and submit them there yourself.

Not affiliated with Xavier University or CampusGroups.
